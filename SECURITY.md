# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.8.x   | Yes       |

## Reporting a vulnerability

Do **not** open a public GitHub issue for security vulnerabilities.

Use [GitHub private vulnerability reporting](https://github.com/taekjaskyli/kafka-canary/security/advisories/new) instead.

Please include:

- Affected version (image tag, Git tag, or commit)
- Impact and a short description of the issue
- Reproduction details if you have them

If the report is accepted, a fix and advisory will be published as part of a patch release.
